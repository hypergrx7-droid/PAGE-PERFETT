Privacy Policy

Last updated: 31 October 2026
Short version: PagePerfect collects no data. It has no account system, no analytics and no advertising. Every scan, image and PDF stays in the app's private storage on your device. The app makes exactly one kind of network request: asking which version is current so it can update itself.

1. Who we are

PagePerfect is a free document scanner application for Android. This policy covers the PagePerfect Android application and this website.

2. Data we collect

None. Specifically:

3. Permissions and why

  • Camera — required to scan documents. Frames are processed on-device in memory.
  • Photos / media (read) — only if you choose to import an existing image.
  • Storage (write) — only to save the PDF or image you asked for.
  • Internet — used for one thing: checking for a new version and downloading its update. The request carries no account, no device identifier and nothing about your documents.
  • Install unknown apps — lets the app hand a downloaded update to Android's own installer. You can revoke it at any time in Settings.

PagePerfect does not upload documents. There is no cloud sync, no backup service, no analytics and no crash reporting in the application. The only hosts contacted are hypergrx7-droid.github.io (a small version file) and github.com (the update APK, if you accept an update).

4. Where your documents live

  • Scans and PDFs are written to the app's private storage directory.
  • If you use Share or Export, the file goes only where you send it (another app, email, cloud drive of your choosing).
  • Uninstalling the app removes its private storage. Files you exported elsewhere are unaffected.

5. Third parties

The app contains no advertising SDK, no analytics SDK, and no third-party tracking library. The only third-party components are open-source libraries listed in the project's THIRD_PARTY_LICENSES.md file, none of which transmit data.

6. Children

The app is suitable for all ages and collects no personal information from anyone, including children under 13.

7. Your rights

Because no personal data is collected or stored by us, there is nothing to access, correct, export or delete on our side. Deleting the app deletes all app data from your device.

8. Distribution and updates

The APK is distributed through GitHub Releases. Downloading from GitHub is subject to GitHub's privacy statement. This website is hosted on a static host and sets no cookies and runs no analytics.

When the app starts it fetches version.json from this site. That file holds a version number and a download link. The request includes no user data. If a newer version exists, the app downloads the APK from GitHub Releases and asks Android to install it. If the check fails — no connection, server down — the app simply opens and works normally.

9. Changes to this policy

If this policy ever changes, the "last updated" date above will change.

10. Contact

Questions about privacy: open an issue at github.com/hypergrx7-droid/PAGE-PERFETT/issues.
