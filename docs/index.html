How to install

  1. Tap the download link and wait for the file to finish.
  2. Open it. Android will say "For your security, your phone is not allowed to install unknown apps from this source."
  3. Tap Settings → enable Allow from this source → go back.

FAQ

Questions

Is it really free? What's the catch?

No catch. There is no paid tier, no ads, no account and no data collection, so there is nothing to monetise. It is built and published by an independent developer.

Why isn't it on the Play Store?

Google charges a one-time developer registration fee. Until that's paid, the APK is published directly on GitHub Releases. You get the exact same app.

Do you collect my documents?

No. The app doesn't even request the internet permission, so it cannot transmit anything. Everything stays in local storage on your device.

Will it work on my phone?

Android 7.0 (API 24) and newer. That covers essentially every phone still in use.

Is the APK safe?

Every APK here is built from the same fixed source tree by an automated pipeline, then checked before publishing: the package id must be com.pageperfect.app and the app must not declare the INTERNET permission. You can verify that yourself on any Android phone with any APK inspector.

Does it scan both sides of a page?

Yes. Two modes: a flip prompt for short documents, and batch mode where you scan all fronts, flip the stack, then scan all backs — it pairs them in the right order automatically.

Can I get true A4 for printing?

Yes, that's the whole point. The PDF page box is exactly 595.28 × 841.89 pt (A4 in PostScript points), so the printer receives a real A4 page instead of a bitmap it has to scale down.
